- 外层新增稳定 `data-variant`，并导出 variant 与 props 类型。

- chat 只收紧排版密度：h1/h2/h3 保留语义层级，段落、列表、引用、表格、代码块和图片使用消息尺度间距。
- 两个 variant 共用唯一 `ReactMarkdown`、components 生成入口、plugins、sanitize schema、URL transform 和图片失败策略。
- Chat 页面尚未接入 renderer；user/assistant 当前呈现和 annotation 均未改变。
